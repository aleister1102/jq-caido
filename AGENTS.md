# jq-caido (Caido JQ plugin)

Caido frontend plugin (Vue 3 + TypeScript) that runs `jq` via `jq-wasm`.

## Quick Reference

| Goal                  | Command           |
| --------------------- | ----------------- |
| Install               | `bun install`     |
| Build                 | `bun run build`   |
| Watch                 | `bun run watch`   |
| Package (release zip) | `bun run package` |

Run from repo root.
